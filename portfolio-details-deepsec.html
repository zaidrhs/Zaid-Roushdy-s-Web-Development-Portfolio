DeepSec Project Details

Project: DeepSec - AI-Powered Intrusion Prevention System

DeepSec is an advanced Intrusion Prevention System (IPS) designed to enhance organizational cybersecurity by proactively detecting and preventing cyber threats using machine learning techniques. By analyzing large volumes of network traffic and user behavior, the IPS identifies anomalies and potential attack patterns in real-time, shifting defense strategies from reactive to predictive.

Core Objectives & Features

  • Real-Time Packet Inspection: Implemented Suricata in inline mode integrated with iptables and NFQUEUE for continuous network traffic monitoring and control.
  • AI-Driven Detection: Integrated an XGBoost machine learning model trained on network flow features to detect and classify unknown attacks, achieving approximately 80% detection accuracy.
  • Automated Threat Response: The system automatically blocks malicious IPs and drops suspicious sessions in real-time without human intervention, minimizing the window of exposure.
  • Interactive Dashboard: A user-friendly visual dashboard (built with Flask) that provides security teams with clear insights into security metrics, live alerts, blocked IPs, and AI predictions.
  • Attack Simulation: Used Scapy and Tcpreplay to simulate network attacks (e.g., port scans, DoS) to test and validate the IPS detection capabilities.

Technical Stack

Security & Networking: Suricata, iptables, NFQUEUE, Wireshark, TCP/IP.
Machine Learning & Data: Python, XGBoost, Pandas, Scikit-learn, Scapy.
Backend & Dashboard: Flask, HTML, CSS, JavaScript, Bootstrap.

System Architecture

The system follows a modular, data-driven architecture consisting of a Data Capture Layer (network traffic), Feature Extraction Layer (preprocessing), Prediction & Classification Layer (XGBoost model), Policy Enforcement Layer (Drop/Block/Alert actions), and a Logging & Reporting Layer. This modularity ensures scalability and low-latency real-time evaluation.
